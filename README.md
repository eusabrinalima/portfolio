# SL. — Portfólio Front-end

Portfólio pessoal desenvolvido para unir formação em **Design Gráfico e Digital** com desenvolvimento **Front-end**, combinando direção visual editorial, tipografia expressiva, alternância entre **Dark / Light Mode** e suporte bilíngue (**PT / EN**).

🔗 **Acesse online:** [eusabrinalima.github.io/portfolio](https://eusabrinalima.github.io/portfolio/)

---

## ✨ Funcionalidades

- **Dark & Light Mode:** Alternância dinâmica de tema com persistência no `localStorage` e gradientes atmosféricos adaptados para cada paleta.
- **Internacionalização (PT / EN):** Tradução instantânea de toda a interface entre Português e Inglês sem recarregar a página.
- **Filtro de Projetos:** Navegação por categorias (`[ TODOS ]`, `[ AUTORAIS ]`, `[ ESTUDOS ]`).
- **Interações Táteis & UX:** Botões com relevo e feedback físico ao clique, além de cópia automática do e-mail para a área de transferência.
- **Responsividade:** Layout fluido e adaptado para desktop, tablet e dispositivos móveis.

---

## 🛠️ Tecnologias & Ferramentas

- **Front-end:** HTML5 Semântico, SCSS (arquitetura modular com partials e CSS Custom Properties) e JavaScript (Vanilla ES6+).
- **Tipografia:** *DM Serif Display*, *Manrope* e *Space Mono*.
- **Design & Prototipação:** Figma, Adobe Photoshop, Illustrator e InDesign.
- **Versionamento & Deploy:** Git e GitHub Pages.
